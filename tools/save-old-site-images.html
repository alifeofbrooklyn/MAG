ดึงรูป Products / Service / Company Profile จากเว็บเดิม

เว็บเดิมไม่อนุญาตให้หน้าอื่นดึงรูป จึงต้องรันสคริปต์สั้นๆ บนหน้าเว็บเดิม (ใช้เวลา 1 นาที)

  1. สร้างโฟลเดอร์ใหม่ D:\MAG\tools\old-site
  2. กดปุ่มนี้เพื่อคัดลอกสคริปต์ →
  3. เปิด https://magconsultant.co.th ใน Chrome หรือ Edge แล้วกด F12 → เลือกแท็บ Console
  4. คลิกในช่อง Console แล้วกด Ctrl+V ตามด้วย Enter
    ถ้า Chrome ขึ้นเตือนเรื่องการวาง ให้พิมพ์ allow pasting กด Enter แล้ววางใหม่อีกครั้ง
  5. จะมีกล่องขึ้นบนหน้าเว็บ → กด เลือกโฟลเดอร์และบันทึก → เลือก D:\MAG\tools\old-site → Select Folder → Edit files
  6. รอจนขึ้น “✓ บันทึกครบ 23 รูป” แล้วบอก Claude ว่าเสร็จแล้ว

สคริปต์นี้แค่อ่านรูปจากเว็บเดิมแล้วบันทึกลงโฟลเดอร์ที่คุณเลือก ไม่ได้แก้ไขอะไรบนเว็บ (ดูโค้ดได้ด้านล่าง)
